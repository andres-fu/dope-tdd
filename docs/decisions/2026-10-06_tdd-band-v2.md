# 2026-10-06 — TDD band v2: Hueso styling, richer cycle stats, test viewer

## What was decided
The `tdd-guard` band grows into a framed Hueso-styled strip (bone background,
ink rule, calavera logo on desktop, `☠` in ember on the terminal) showing:
phase with a red timer, current module, layer + language badge, the test file's
last-modified time, the last 10 runs as a trail, red→green cycle count and
average, test-first ratio and blocked count. Buttons: View test (opens a pane
with the test source), Pause guard (escape hatch; paused edits don't count as
test-first), Reset (zeroes stats, keeps pause and unlocked modules). A minute
tick redraws the time-based fields.

Colors: bone/ink/dim/ember from andresfuentes.net's Hueso tokens, plus two
functional hues — a muted green for passes and a slate for backend badges.
Layer is a folder/extension heuristic: frontend (components, pages, hooks,
.tsx, App, main), backend (server, api, routes, db), logic (everything else).

## Why
The owner wants the cycle legible at a glance and on-brand. Hueso rations color
to ember; strict adherence would make pass/fail and layer harder to scan, so
two muted functional hues are admitted inside an otherwise Hueso frame.

## Alternatives considered
- Strict Hueso (ember family only) — most on-brand, less scannable.
- Ember-forward loud strip — strongest poster energy, least calm while working.
- Opening the test in the IDE — no editor-open call exists in the mod API.

## Trade-offs accepted
- throughline has no backend; the layer badge is a convention guess.
- Fonts (Anton, JetBrains Mono) can't be set in the band; uppercase tracked
  labels and heavy rules carry the poster feel instead.
- The logo SVG is copied into the mod folder, so it can drift from the site's.
