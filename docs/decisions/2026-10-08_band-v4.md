# 2026-10-08 — Band v4: the band shows the evidence, and explains itself

## What was decided
The band now represents what the engine proves, in three rows:

1. `☠ RED FIRST · <phase> · <run trail>` where the phase is PAUSED, IDLE,
   WRITING (with the cycle timer), RED (timer, alarm colour after ten
   minutes) or GREEN.
2. `<MODULE> · SAW RED | NEVER SAW RED · CAUGHT | MISSED | UNVERIFIED | REFACTOR`
   for the current module: whether this cycle's test failed before the code
   made it pass, and what the catch check found for the last change.
3. `CYCLES n · n CAUGHT · n MISSED · n REFACTOR · n NEVER SAW RED · n UNGUARDED · n BLOCKED · MODE WARN`
   with zeros dimmed, warnings in amber, misses in ember, and the mode shown
   only when it is not plain enforce. Then the buttons: VIEW TEST, PAUSE or
   RESUME GUARD, RESET.

Dropped: the layer and language badge, the test file's UPDATED time, the
average cycle time, and the test-first ratio. Added: `/tdd why`, one line per
word that can appear on the band. IDLE is drawn as IDLE, not WRITING.

## Why
"The UI should make sense and tell you what it is so you understand." The
v3 band showed process stats (cycles, averages, layer) that said nothing
about whether the tests could be trusted. The engine now has the answers
(saw red, caught, missed, refactor credit, mode), so the band shows those and
nothing else. The ratio and the averages invited reading them as scores,
which the research on developer metrics warns against; `/tdd` still prints
them for the person who wants the numbers.

## Alternatives considered
- Keep every v3 field and add the new ones: too wide for a terminal and
  back to a dashboard.
- A separate evidence pane with one row per change: the right next step for
  pairing, not a replacement for a glance.

## Trade-offs accepted
- The verdict words apply to the current module only; the tally carries the
  rest of the session.
- The title is RED FIRST while the name is undecided; it is one constant.
- The skull and ember remain the owner's brand; a neutral theme is still
  pending for a public release.
